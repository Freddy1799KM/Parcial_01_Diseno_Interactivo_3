VARIABLES: una variable es como una "capsula" que nos sirve para guardar o almacenar datos con los que posteriormente podemos trabajar haciendo operaciones matematicas, haciendo comparaciones

STRING:Los String es una forma de "almacenar" datos pero estos datos son de tipo texto y tiene la particularidad de que deben ir dentro de " " o de ' ' de esta forma podemos saber que dentro de estos simbolos hay texto 

FUNCIONES:Las funciones son como una forma de almacenar variables para lograr operarlas o hacer procedimientos de manera interna y podemos usarlas en cualquier momento

    ARGUMENTOS:Los argumentos de una funcion son como todos los parametros a trabajar o operar dentro de la funcion y podemos agregar tantos como sean necesarios
    RETURN:El return es la manera en la cual "sacamos" el resultado de una funcion ya que realizamos procedimientos en una funcion estos no generan una salida y debemos sacarla 

DECLARACIONES:
    IF: el if es para controlar el flujo de toda aquella validacion que necesitemos poniendolo en otras palabras genera unos "caminos" donde si cumples la condicion sigues el camino o te lleva pór un camino diferente 

VALORES BOOLEANOS:Los valores booleanos provienen directamente de los numeros binarios donde basicamente solo existen 2 estados posibles true o false
    TRUE:En true basicamente vamos a difinir si la condicion que estamos evaluando es verdadera o correcta 
    FALSE:En False definimos si la condicion que estamos evaluando nos genera que es incorrecta o que directamente no cumple 

FOR: Los for se conocen como bucles, basicamente ciclos que se repiten hasta que obtengamos el resultado deseado o la condicion evaluada en el momento a diferencia del if el for es como una manera de decir cuantas veces necesito que se repita el ciclo 

&&: se lee o representa "y" o "and" y nos sirve para envualuar 2 condiciones que si o si deben cumplirse para que sean verdaderas o correctas 

||: se lee o representa "o" o "OR" donde estamos evaluando 2 condiciones pero con que una de ellas sea correcta nos sirve para que sea verdadera o correcta

!: cuando usamos este signo lo que nos quiere decir es que estamos evaluando lo contrario es decir si estoy evaluando que una X debe ser igual a 1 se representa asi X===1 donde si o si debe ser uno pero si usamos el signo ! decimos que X !== 1 estamos declarando que X debe ser diferente de 1 para que sea verdadero o correcto

Array: los arreglos o matrices visualmente lo debemos ver como cubos o capsulas que sirven para almacenar, organizar o estructurar datos o informacion donde vamos a tener unas posiciones por ejemplo en una matriz 3x3 tenemos los nombres de 9 personas y estamos buscando a Samuel donde samuel estaria en la posicion 4 y se alli no se movera o cambiara s
