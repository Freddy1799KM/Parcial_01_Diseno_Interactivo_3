VARIABLES: una variable es como una "capsula" que nos sirve para guardar o almacenar datos con los que posteriormente podemos trabajar haciendo operaciones matematicas, haciendo comparaciones

STRING:Los String es una forma de "almacenar" datos pero estos datos son de tipo texto y tiene la particularidad de que deben ir dentro de " " o de ' ' de esta forma podemos saber que dentro de estos simbolos hay texto 

FUNCIONES:Las funciones son como una forma de almacenar variables para lograr operarlas o hacer procedimientos de manera interna y podemos usarlas en cualquier momento

    ARGUMENTOS:Los argumentos de una funcion son como todos los parametros a trabajar o operar dentro de la funcion y podemos agregar tantos como sean necesarios
    RETURN:El return es la manera en la cual "sacamos" el resultado de una funcion ya que realizamos procedimientos en una funcion estos no generan una salida y debemos sacarla
